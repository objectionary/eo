1# Makes an `input` from bytes.
2# It is taken off a sequence of bytes, or off any object that can be
3# dataized via `as-bytes`.
4# Here's how you can read portions of bytes from the input:
5# ```
6# as-input > i
7# 01-02-03-04-05-06-07-08-F5-F6
8# seq > @
9# *
10# i # error
11# i.read 4 > i1 # 01-02-03-04
12# i1.read 4 > i2 # 05-06-07-08
13# i2.read 4 > i3 # F5-F6
14# i3.read 3 > i4 # --
15# ```
16# Here every `read` object returns input block.
17# Every input block is a requested portion of bytes, so it's dataizable.
18# Also every input block has object `read` which allows to get
19# next input block with next potion of bytes.
20# If requested amount of bytes is more than amount
21# of available bytes - only available bytes are included.
22# If there's no available bytes - empty bytes (`--`) are included.
