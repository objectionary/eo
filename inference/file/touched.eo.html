1# Touches a file, creating it if it does not exist yet, and returning the same
2# file, unchanged, if it already does. It is a method of `file`, and `f` is the
3# file it is taken off. `f.exists` counts any symbolic link, dangling or not,
4# as existing, so this checks reachability directly instead: an ordinary
5# absent path or a dangling symlink both get created. On POSIX, opening a
6# symlink is done without the exclusive flag, since POSIX defines
7# `O_CREAT | O_EXCL` on a path naming a symlink as always failing `EEXIST`,
8# whether or not its target exists; the exclusivity that guards the
9# plain-file race stays for every other path, and win32 keeps its exclusive
10# open unconditionally, since its reparse points do not share that rule.
11#
12# @todo #7077:60min Add a synchronization-based regression test that creates
13# the target file between the exists() probe and the exclusive open below,
14# so the race this fixes is actually exercised. A single-threaded EO `++>`
15# test can't trigger it: `f.exists.if` always sees a consistent snapshot in
16# one thread. It needs a JUnit test against the generated `EOtouched` class
17# (see PhDefaultRaceTest.java for the com.yegor256.Together idiom this repo
18# already uses for exactly this kind of interleaving), with one thread
19# paused right after the exists() probe while another thread creates and
20# writes to the file, then confirms the paused thread's touched() does not
21# truncate it.
