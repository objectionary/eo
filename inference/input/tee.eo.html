1# Tee input is an input that reads from the input it is taken off, writes to
2# provided `output` and behaves as that same input. It is a method of
3# `input`, and `origin` is the input it is taken off.
4# To copy bytes input to memory you can do:
5# ```
6# malloc.of > copied
7# 5
8# [m]
9# read. > @
10# tee.
11# input 01-02-03-04-05.as-input
12# m.to-output
13# 5
14# ```
15# After dataization `copied` is equal to `01-02-03-04-05` which are read
16# from memory.
