1# Boolean value, parameterized by its choice `if`.
2# `if` is a two-argument object that returns either its first argument
3# (for TRUE) or its second one (for FALSE). Both the byte representation
4# and every other operation are derived from this single choice, so no
5# conditional primitive is needed and `true`/`false` are simply two
6# applications of `bool`.
7#
8# TRUE carries the byte `FF-` and FALSE the byte `00-`, so the two are
9# complementary masks: the bitwise `and`, `or` and `not` of `bytes`
10# answer over them exactly what `if` answers. `FF-` is also no character
11# at all, so a boolean no longer passes for the one-byte text U+0001,
12# the way it did when TRUE was `01-`.
