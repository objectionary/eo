1# Hash-map.
2# Here `pairs` must be a `tuple` of `map.entry` object.
3# The `map.entry.key` must be a dataizable object, `map.entry.value` may be any object.
4# Two keys are the same only when their hash codes and their raw bytes are equal.
5# A hash code alone is not enough, since `bytes.hash` is a `31 * acc + byte`
6# polynomial and therefore has collisions, e.g. `"Aa"` and `"BB"` both hash to 2112.
7# Comparing hash codes only would make such distinct keys overwrite each other.
8# Every key is dataized to bytes exactly once, when the map is built, and the
9# hash code is derived from those bytes rather than from the key itself,
10# so that keys with side effects are never evaluated more than once.
11# A key that is not there is reported by the key itself and not by its hash
12# code, which is a number the caller never saw: the bytes are printed as text
13# where they decode as UTF-8, and in hexadecimal where they do not.
