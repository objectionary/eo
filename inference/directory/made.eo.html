1# Creates a directory, making missing parent directories as needed. It is a
2# method of `directory`, and `d` is the directory it is taken off. When the
3# path already exists, it must already be a directory: if a regular file (or
4# any non-directory entry) occupies the path, the computation terminates
5# instead of returning that entry decorated as a directory.
6#
7# The path may be made by somebody else between the question and the answer,
8# so a `mkdir` coming back with `EEXIST` over a directory is taken for the
9# directory it names rather than for a failure. `EOdirectoryEOmadeRaceTest`
10# holds the interleaving that reaches that branch.
