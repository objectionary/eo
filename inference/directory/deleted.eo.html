1# Recursively deletes a directory and all of its contents. It is a method of
2# `directory`, taken off the directory it deletes. The walk that feeds
3# `entries` reports everything underneath that directory and never the
4# directory itself, so the recursion below empties it but leaves it standing.
5# The root is removed by the step after it, once the walk is done and the
6# directory is empty, through `file.deleted`, which reaches for `rmdir` over
7# `unlink` when the path it is given is a directory.
