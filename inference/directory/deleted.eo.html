1# Recursively deletes a directory and all of its contents. It is a method of
2# `directory`, and `d` is the directory it is taken off. The walk that feeds
3# `entries` reports everything underneath `d` and never `d` itself, so the
4# recursion below empties the directory but leaves it standing. The root is
5# removed by the step after it, once the walk is done and the directory is
6# empty, through `file.deleted`, which reaches for `rmdir` over `unlink`
7# when the path it is given is a directory.
