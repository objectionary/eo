1# Object that allows choosing the right options according to case conditions.
2# Parameter `cases` is an array of two-dimensional arrays, which
3# consist of condition bool value and expected value, if this
4# condition is true. For example:
5#
6# ```
7# switch
8# *
9# *
10# true
11# "this value will be returned"
12# *
13# false
14# "this value will be skipped"
15# ```
16#
17# This object returns the value of the first true statement,
18# or invokes `fallback` with a descriptive message when `cases`
19# is empty or when every case condition is false.
