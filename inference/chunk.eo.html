1# Handle to a block of data allocated in heap memory.
2# It is created by `malloc.of` (and, indirectly, by `malloc.empty` and
3# `malloc.for`) and passed into the user scope, where it provides the API
4# to read and write the data of the block:
5#
6# ```
7# malloc.of
8# 8 # allocate 8 bytes length block in memory
9# [c]
10# seq * > @
11# c.write 2 "Hello" # write "Hello" at offset 2 -> the bytes written
12# c.read 3 4 # read 4 bytes from offset 3 -> "ello"
13# c.put 42 # write object 42 with offset 0
14# c.get # get all the data from the memory block -> 42
15# c.size # get size of the block
16# c.id # get identifier of the block
17# c.@ # the same as c.get
18# ```
19#
20# The `id` is the identifier the allocator gave to the block.
