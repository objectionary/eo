1# TRUE when the number is a valid eight-byte IEEE-754 value that is neither
2# infinite nor not-a-number. A byte sequence of any other width can never
3# represent a number, so it is not finite: `is-nan` returns FALSE for such
4# widths, which would otherwise let them fall through as finite.
