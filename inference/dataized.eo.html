1# Object that dataizes `target`, makes a new instance of `bytes` from given
2# data and behaves as the result
3# `bytes`.
4# The object is used as implementation of caching syntax (`!`).
5# The next two lines of code behave identically:
6#
7# ```
8# some-object > cached!
9# (dataized some-object).as-bytes > cached
10# ```
11#
12# Dataization is a process of retrieving data (bytes) from an object
13# by taking its \Delta attribute.
14# An example of usage:
15#
16# ```
17# # Example object with nested structure for dataization demonstration.
18# [] > foo
19# [] > @
20# inner.five > @
21# [] > inner
22# 5 > five
23#
24# (dataized foo).as-bytes > result # result is 00-00-00-00-00-00-00-05
25# result.as-number > f # f is 5
26# ```
27#
28# Here, when `.as-bytes` is taken, the `dataized` dataizes (takes `bytes`)
29# from the object `foo` and returns them.
30# The `.as-bytes` is used to prevent double dataization.
