1# Convenient wrapper `stderr` which uses the operating system console
2# as an error output only and allows to print the given argument to the
3# standard error stream as `string`:
4# ```
5# [args] > app
6# Q.stderr > @
7# "Something went wrong!\n"
8# ```
9#
10# Here the "Something went wrong!" string is printed to the operating
11# system standard error stream (file descriptor 2). The object writes to
12# the console in a platform-specific way, with different implementations
13# for POSIX and Windows systems.
