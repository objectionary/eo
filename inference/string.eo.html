1# Object `string` represents UTF-8 encoded text strings stored internally
2# as byte sequences. It provides Unicode-aware operations for text manipulation
3# including slicing, length calculation, and character-level access.
4# Unicode characters may occupy 1-4 bytes each, so byte length differs from
5# character length for non-ASCII text.
6#
7# Usage examples:
8# ```
9# string "Hello, \u4e16\u754c!" # Unicode string creation
10# "text".length # Character count (not bytes)
11# "text".slice 0 2 # Character-based slicing
12# "TEXT".lower # Lower case, default English rules
13# "text".upper # Upper case, default English rules
14# "text".turkish.upper # Upper case, Turkish dotted/dotless I
15# ```
16# Case conversion is exposed as string methods `lower` and `upper`, backed
17# by the locale wrappers `string.english` (the default) and `string.turkish`.
18# .
