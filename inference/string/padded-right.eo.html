1# Returns the string padded on the right with `fill` until it counts `width`
2# characters, so that `x` padded to five characters with a space
3# becomes `x `. Characters are counted, and not bytes, so a multi-byte
4# character widens the text by one. A string of `width` characters
5# or longer is returned unchanged.
6# If `width` is not a finite non-negative integer (negative, fractional, nan
7# or infinite), or `fill` is not a single character, the `cant-pad` fallback
8# takes an error message. When unbound, it terminates with that message.
