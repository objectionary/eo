1# Returns the string in upper case, using the default English casing rules.
2# This is a thin string method: `"hello".upper` is the same as
3# `(string.english "hello").upper`. Only the ASCII letters `a`-`z` are
4# folded; every other byte, including accented Latin, Cyrillic and Greek
5# letters and all multi-byte UTF-8 sequences, passes through unchanged.
6# For locale specific rules use a locale wrapper such as `string.turkish`,
7# as in `"...".turkish.upper`.
