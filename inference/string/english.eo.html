1# English locale wrapping a `string` and exposing case conversion for it.
2# Being a decorator of its string, an `english` object behaves like the
3# string itself (`.length`, `.eq`, `.slice` and so on pass through), while
4# adding `lower` and `upper` that map the ASCII letters `A`-`Z` and `a`-`z`
5# to their counterparts one-to-one. Every other byte, including accented
6# Latin, Cyrillic and Greek letters and all multi-byte UTF-8 sequences,
7# passes through unchanged. This is the language-neutral default, which is
8# equivalent to English since English has no special casing rules. Locales
9# that diverge from it, such as `string.turkish`, specialize this object.
10# Each conversion hoists its lower letter bound into a `mincode` constant, so
11# the bound is computed once rather than for every byte walked.
