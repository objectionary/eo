1# Counts the characters in the string, and not its bytes. The UTF-8 sequence
2# is walked character by character, so a multi-byte character counts as one.
3# Every multi-byte sequence is validated against the UTF-8 rules of the
4# Unicode standard (Table 3-7): the leading byte fixes the character width and
5# each following byte must be a `10xxxxxx` continuation byte, while the second
6# byte is additionally range-checked so that overlong encodings (`C0`/`C1`
7# leads, `E0` with an `80`-`9F` second byte, `F0` with an `80`-`8F` second
8# byte), UTF-16 surrogates (`ED` with an `A0`-`BF` second byte) and code points
9# above U+10FFFF (`F4` with a `90`-`BF` second byte, and `F5`-`FF` leads) are
10# rejected. A sequence that is incomplete or malformed terminates the
11# computation, exactly like `slice` does for a truncated character.
