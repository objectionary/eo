1# Returns the string in lower case, using the default English casing rules.
2# This is a thin string method: `"HELLO".lower` is the same as
3# `(string.english "HELLO").lower`. Only the ASCII letters `A`-`Z` are
4# folded; every other byte, including accented Latin, Cyrillic and Greek
5# letters and all multi-byte UTF-8 sequences, passes through unchanged.
6# For locale specific rules use a locale wrapper such as `string.turkish`,
7# as in `"...".turkish.lower`.
