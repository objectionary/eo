1# Returns the original `text` as `number`.
2# If the text is not numeric, the `cant-parse` fallback is returned,
3# or the terminator when unbound.
4# The whole `text` must be the number: `scanf` matches its `%f` pattern
5# unanchored (via `find`), so on its own it would accept any text that
6# merely contains a number-shaped substring, e.g. `"$100"` or `"12.34.56"`.
7# The text is therefore validated against the anchored equivalent of that
8# same `%f` token, so that only a text that is entirely a number is parsed.
