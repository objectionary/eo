1# Regular expression in Perl format.
2# The pattern is the string it is taken off.
3# It starts and ends with slash (e.g. "/(your-expression)/"),
4# Also it can be specified by the flag option,
5# e.g.
6# ```
7# (`Q.string.regex "/(word)/i").compiled.matches "WORD"
8# ```
9#
10# There are two entry points and one letter between their names.
11# `matches` answers whether the whole text matches: the block it finds has
12# to start at zero and end at the length of the text, so a pattern that
13# covers only part of it answers `false`.
14# `match` searches instead: it hands back the first block found anywhere in
15# the text, and `next` moves to the one after it.
16# ```
17# (`Q.string.regex "/[a-z]+/").compiled.matches "1abc" # false
18# (`Q.string.regex "/[a-z]+/").compiled.match "1abc" # the block "abc"
19# ```
20#
21# Supported flags:
22# /d - Enables Unix lines mode.
23# /i - Enables case-insensitive matching.
24# /x - Permits whitespace and comments in pattern.
25# /m - Enables multiline mode.
26# /s - Enables dotall mode.
27# /u - Enables Unicode-aware case folding.
