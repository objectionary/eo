1# Returns the first `limit` characters of the string, so that `Jeffrey`
2# truncated to three characters becomes `Jef`. Characters are counted, and
3# not bytes, so a multi-byte character counts as one. A string of `limit`
4# characters or shorter is returned unchanged, which is how this differs
5# from `slice`, where a `limit` beyond the end of the string terminates the
6# computation.
7# If `limit` is not a finite non-negative integer (negative, fractional, nan
8# or infinite), the `cant-truncate` fallback is returned, or the terminator
9# when unbound.
