1# Temporary directory.
2# For Unix/MacOS uses the path supplied by the first environment variable
3# found in the list TMPDIR, TMP, TEMP, TEMPDIR.
4# If none of these are found, "/tmp" is used.
5#
6# For Windows uses the path reported by the Windows "GetTempPath" API function which
7# takes the first environment variable in the list TMP, TEMP, USERPROFILE.
8# If none of these are found, it returns the Windows directory (C:\Windows).
9#
10# A trailing separator of the supplied path is dropped, the way macOS sets
11# TMPDIR, so that the path of a temporary file is this path, one separator
12# and a name, and its dirname is this path again.
