1# Loop `while` with a pre-condition.
2# Here's how you can use it:
3# ```
4# while > last
5# i.lt 5 > [^ i]
6# [i]
7# "Iteration %d\n".printf > @
8# * i
9# ```
10#
11# Here the behaviour of `while` would be identical to:
12# ```
13# seq > last
14# *
15# dataized "Iteration 0\n"
16# dataized "Iteration 1\n"
17# dataized "Iteration 2\n"
18# dataized "Iteration 3\n"
19# dataized "Iteration 4\n"
20# ```
21#
22# Only the first four strings are dataized for side effects while the last one
23# is returned as the result value assigned to the `last` object.
24# The `while` loop example produces identical behavior.
