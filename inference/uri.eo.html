1# Parses an RFC 3986 generic URI `text` and exposes its components as
2# read-only attributes: `scheme`, `authority` (together with `userinfo`,
3# `host` and `port` parsed out of it), `path`, `query` and `fragment`.
4#
5# Usage, without an authority:
6# ```
7# uri "pgsql:localhost:899" > x
8# x.scheme > s # pgsql
9# x.path > p # localhost:899
10# ```
11# With a "//" authority:
12# ```
13# uri "pgsql://localhost:899" > x
14# x.host > h # localhost
15# x.port > p # 899
16# ```
17#
18# The object is immutable: it only reads parts of `text` and has no mutators.
