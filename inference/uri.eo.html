6# ```
7# uri "pgsql:localhost:899" > x

9# x.path > p # localhost:899
10# ```
11# With a "//" authority:
12# ```
13# uri "pgsql://localhost:899" > x
14# x.host > h # localhost

16# ```
17#
18# The object is immutable: it only reads parts of `text` and has no mutators.
