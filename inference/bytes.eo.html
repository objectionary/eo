1# Object `bytes` encapsulates a chain of bytes, providing the bitwise and
2# structural atoms every data object relies on. Objects like `number`, `string`,
3# and the integer types (`i16`, `i32`, `i64`) use `bytes` as their internal
4# representation, while conversions and derived operations arrive from the
5# `bytes` package as attributes of this object (e.g. `01-02.as-number`).
6#
7# Usage examples:
8# ```
9# bytes 01-02-03 # Creates a 3-byte sequence
10# FF-FF.and 00-FF # Bitwise AND operation
11# 01-02.as-number # Convert 8-byte sequence to number
12# ```
13# .
