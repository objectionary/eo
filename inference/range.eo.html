1# Range - create a `list` containing a range of elements
2# Here `start` must be an abstract object that must have an object `next` to get
3# next element and object `lt` to compare with the `end` object.
4# Every next element also must have objects `next` and `lt`.
5# The first object in the chain must have a default value
6# e.g.:
7#
8# ```
9# range
10# []
11# [num] > build
12# num > @!
13# build (@.plus 1) > next
14# build 1 > @
15# 10
16# ```
17#
18# Here the first argument is an abstract object that has a default value - 1 and
19# it also has object `next`. The next object after first is decorator of
20# `1.plus 1` and also has object `next`. Since these objects are ints - they have
21# object `lt` by default.
